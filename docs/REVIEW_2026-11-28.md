- **기존 버전**: `main` (5d61512 + 당시 미커밋 `phone_login.py` 수정)

## Cloudflare 대기 — 기존 vs 수정

| | 기존(main 5d61512) | 리팩토링 직후 | **지금** |
|---|---|---|---|
| 최대 대기 | 15초 자동 + 10초 사용자 | 15초 + 300초 | **60초 (한 번에)** |
| 확인 간격 | 약 0.4초 + dump 시간 | 같음 | **처음 즉시, 이후 3초** |
| 체크 칸 탭 | 탭 시도함 | 안 함 | 안 함 |
| 화면 인식 실패 | 일부 경우 통과로 처리 | 빈 화면은 제외 | **dump 실패·빈 WebView·폼 아님 = 실패로 봄**, 위젯 없는 폼은 2번 연속 확인돼야 통과 |
| 일시정지·중지 | 반응 안 함(대기 끝날 때까지) | 반응 안 함 | **0.2초 안에 반응** |
| 시간 초과 | 로그인 중단 | 로그인 중단 | `CLOUDFLARE_TIMEOUT` 로 그 계정 실패 기록, 재시도 없음 |
| 웹 표시 | 없음 | 상태만 | **남은 초를 1초마다 표시** (진행 상황 + 노란 배너) |

## 중복 결제·오류 복구 (테스트로 확인)

| 상황 | 동작 | 테스트 |
|---|---|---|
| 결제 인증 후 완료 화면 못 봄 | `결과 불명` 기록 → 작업 전체 정지 → 그 계정 재결제 거절 | `test_unknown_blocks_and_prevents_repay` |
| 결제 도중 프로그램 종료 | 다시 켜면 결제 기록 `결과 불명`, 작업은 자동 재시작 안 함 | `test_recover_after_restart` |
| 주문번호 없이 '결제됨' 확정 | 거절 | 같은 테스트 |
| 같은 작업 두 번 실행 / 새로고침 | 거절 / 아무것도 실행 안 함 | `test_double_start_rejected`, `test_get_pages_do_not_start_anything` |
| 결제 전 ADB 끊김 | 재연결 후 그 계정 처음부터 1회 재시도 | `test_disconnect_retries_from_start` |
| 배송지 불일치·금액 초과 | 결제하기 누르기 전 멈춤(결제 기록 0건) | `test_wrong_address_stops_before_payment`, `test_amount_limits` |
| 다른 사이트에서 몰래 요청 | 403 거절 | `test_csrf_and_host_blocked` |

## 남은 고정 대기 (속도)

| 위치 | 대기 | 판단 |
|---|---|---|
| 로그아웃 후 로그인 전 (`relogin`) | 2초 | 기존 실측 경로에서 쓰던 값 — 폰 검증 없이 지우지 않음 |
| 로그인 후 결제 전 (`relogin_and_pay`) | 1초 | 같음 |
| 앱 실행 직후 (`open_app`, `open_my_page`) | 2초 | 같음 |
| 키보드 내림·입력 사이 | 0.2~0.5초 | 입력 누락 방지용, 유지 |
| PIN 숫자 사이 | 0.5초 | 카드앱 입력 안정성, 유지 |
| **계정 사이 쉬는 시간** | 30초 (기본) | 사용자 요청 기능. 작업 등록 때 0~600초로 조절 |
| `uiautomator dump` | 1회 약 3초 | **가장 큰 병목.** 인증 성공 후 다시 읽던 1회는 이번에 없앰 |

고정 대기 2초·1초는 폰을 연결해 dry-run 으로 확인한 뒤 줄일지 판단하는 게 안전하다.
