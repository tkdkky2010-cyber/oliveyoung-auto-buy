# 올리브영 앱 주문서 실측 (2026-11-04, 앱 ver 3.59.0, 1080x2400)

1번 계정, 헤트라스 수선화 ×3 (55,500원)으로 **결제하기 직전까지** 실측. 결제하기(`btnPay`)는 누르지 않았다.
주문서·장바구니는 전부 WebView — dump 의 resource-id = HTML id. 뒤쪽 숨은 WebView 노드도 같이 잡히니 `bounds != [0,0][0,0]` 만 본다.

## 카드 규칙 (사용자 지시 2026-11-04)
- **삼성 쓰지 말 것. 현대·롯데만.** 1번 = 롯데카드(사용자가 직접 선택).

## 1. 장바구니
- 진입: 마이페이지 헤더 `headerBasket` (홈 상단 가방 아이콘도 같은 위치).
- 첫 진입 시 하단 시트 `장바구니가 달라졌어요!` → **확인** (dump 에 없음 → OCR, 실측 (540,2150)).
- 상품 확인(dump 로 정확히 읽힘): CheckBox desc `<상품명> 선택`, 옵션 TextView, 수량 `EditText`(값=수량), `전체 (n/m)`.
- 주문: 버튼 텍스트 `일반배송 구매하기 (N건)` (dump·OCR 둘 다 잡힘).

## 2. 주문서 — 배송지
- `addrSummaryName` = 배송지 이름(예 `1(김건엽)`), `baseDlvpYnFlag` = `기본배송지`, 옆 `변경` 버튼.
- ⚠️ 배송지 변경 목록 화면은 미실측 (1번은 기본배송지가 이미 맞았음).

## 3. CJ ONE 전액사용
- 보유 `point_cjop_label` (예 `2,379P`), 입력 `cjonePntAplyAmt`, 버튼 `cjonePnt_btn`.
- 누르면 네이티브 알림 `CJ ONE 포인트는 10P 단위로 사용하실 수 있어요.` → `button1`(확인).
  알림이 떠 있는 동안 dump 엔 주문서가 안 잡힌다 → 확인 후 다시 읽을 것.
- 적용 검증(실측): `cjonePntAplyAmt`=`2370`, `point_cjop_label`=`9P`, `totPntAplyAmt`=`- 2,370`,
  `totPayAmt_tit_span` 55,500 → `53,130` (= 상품금액 − 차감). **이 셋이 안 맞으면 멈출 것(조용한 SKIP 금지).**
- ★**현재 규칙 (사용자 지시 2026-11-05): `전액사용` 만 누르고 적용 여부는 보지 않고 넘어간다.** 위 멈춤 규칙을 대체한다.
  실측: 2,650P 는 알림 없이 전액 적용, 345P 는 눌러도 반응 없음(최소 사용 기준은 미확인).

## 4. 결제수단 → 카드종류
- `paymethod-menu2` = 일반결제 라디오(기본 선택), `paymethod-menu1` = 올영PAY.
- `payMethod_11` = 신용카드(기본 선택). 그 외 `_29` 네이버페이 `_26` 카카오 `_84` 토스 `_25` 페이코 `_22` 휴대폰 `_21` 계좌이체.
- 카드종류 `acqrCd` (기본값 `현대카드`) 탭 → **네이티브 선택창** `CheckedTextView` text1:
  현대카드 / 삼성카드 / 신한카드 / 롯데카드 / BC카드 / 하나(외환)카드 / NH카드 / 우리카드 / 카카오뱅크 / 씨티카드 / 광주비자 / 전북카드
- 선택 검증: `acqrCd` text 가 카드명으로 바뀐다(실측). 할부 `instMmCnt` = `일시불`.
- 화면 위쪽 `즉시할인 혜택`(올영PAY X 현대카드 Plus 20,000원 / 올영PAY X 농협 4,000원)은 **올영PAY 전용** — 일반결제엔 해당 없음.

## 5. 모두 동의
- `auto-all-check` CheckBox — ⚠️ **dump 의 checked 가 안 바뀐다**(체크해도 false).
- ⚠️ 체크박스 자리 탭은 반응 없음. **`모두 동의합니다` 글자(OCR) 탭**으로 체크됨(실측).
- 검증 = 스크린샷 픽셀: 체크박스 bounds 안쪽 평균 밝기 미체크 254 / 체크 43 (어두운 픽셀 88%).
- 바로 위 `savePayMethodYn`(지금 설정한 배송지와 결제정보를 기본으로 사용하기)은 기본 체크.

## 6. 주문서 스크롤 (사용자 지시 2026-11-05)
- 전액사용 후 **아래로 2번 → 200px 올림**. 카드 칸이 화면 위로 벗어나 있으면 그때만 더 올린다. 계속 내리지 말 것.
- 카드 칸·`모두 동의합니다`·결제하기가 한 화면에 들어오는 배치: `acqrCd` y≈387, `auto-all-check` y≈1320, `btnPay` y≈1562.
- 카드 선택창 항목 위치 고정: 현대 (540,210) / 롯데 (540,759). 창이 닫히며 화면이 밀리므로 **선택 후 위치를 다시 읽는다.**
- `모두 동의합니다` 는 글자가 보여도 OCR 이 못 읽을 때가 있다 → 위치는 dump 의 `auto-all-check`, 탭은 그 행 x=270.
- 배송지: 지금은 기본배송지인지만 확인한다. 오른쪽 위 `변경` 으로 주소지를 바꾸는 단계는 사용자가 추후 추가 예정. 이름 앞 숫자(`1(…)`)는 계정 번호가 아니다.

## 7. 결제하기 이후 — 롯데 (2026-11-05 실측)
1. `btnPay` → 롯데 결제창. **dump 에 안 잡히고 뒤 주문서만 나온다** → OCR 로 `로카페이` 확인 후 `결제하기` 탭.
2. LOCA 앱 `PayRequestActivity`: 금액·`CJ올리브영` 확인 → `bt_appcard_pay_request_payment`. 카드 선택 불필요(한 장뿐).
3. `SimpleNumberAuthActivity`: 셔플 키패드, `content-desc` 로 dump → `input_pin("lotte")`, 6자리 후 자동 제출.
4. `결제 요청되었습니다` → `bt_appcard_pay_request_complete_confirm` → 올리브영 복귀 → `주문을 완료했어요!`, 주문번호 `Y…`. 구글플레이 리뷰창이 뜨면 `나중에`.

## 8. 결제하기 이후 — 현대 (미실측)
- 현대카드 앱에서 **`The CJ-M Edition2`** 선택(사용자 지정). 3mall 기준 경로는 앱 강제 종료 → 카드 선택 → `결제 비밀번호 인증` → `desc='N 버튼'` 셔플 키패드. `phone_pay` 는 아직 미지원이라 멈춘다.
- 3mall 의 "현대몰 앱카드 금지" 는 올영에 해당 없다. 올영은 결제하기 후 뜨는 앱에서 끝까지 진행한다(사용자 확인).

## 9. 로그인·로그아웃 함정 (2026-11-05 실측)
- 로그아웃: 마이페이지 맨 아래 `로그아웃` → 알림 `확인`. 장바구니·주문서엔 하단 탭이 없어 뒤로 가야 한다.
- ⚠️ **로그인 폼의 맨 아래 `회원가입` 이 `마이` 탭과 같은 자리**다. 폼이 열렸으면 그 좌표를 다시 누르지 말 것(실제 오탭 사고).
- 저장된 아이디가 칸에 미리 들어 있다 → 지우고 입력한다. 안 지우면 이어 붙어 값 확인에서 실패하고 느린 경로로 빠진다.
- 푸시 알림이 화면 위쪽을 덮으면 오른쪽 위 장바구니 탭이 씹힌다. 탭 뒤 화면 전환을 확인하고 다시 누른다.
- `uiautomator dump` 는 1회 약 3초가 걸리는 최대 병목. OCR 은 약 1초지만 위 사례처럼 놓칠 수 있다.

## 10. 검증 현황 (2026-11-05)
- 1번 롯데: 대화형으로 끝까지 결제 성공, 주문 `Y2611059661356` / 104,950원.
- 2번 롯데: `phone_pay` 로 PIN 화면까지 확인, PIN 입력 시 사용자가 직접 닫아 주문 없음(95,600원 미결제).
- ⚠️ **미검증:** `phone_pay` 로 PIN 입력부터 주문 완료 판정까지의 전 구간, 저장된 아이디 지우기(모의 테스트만), 현대카드 전 구간.
- 시간(직전 실행): 로그인 약 42초(아이디 문제로 느린 경로 포함), 주문서 → PIN 화면 약 18초.

## 11. 쓰레드 → 올영 앱 상품 → 바로구매 (`threads_buy.py`, ⚠️ 전부 미실측 2026-11-10)
- 시작 시 `open_app` → 마이 탭 닉네임으로 계정 확인(로그인은 안 함).
- 쓰레드 링크를 `am start -a VIEW` 로 연다. 앱으로 열릴지 브라우저로 열릴지 미확인.
- 글에서 `oliveyoung.co.kr` / `oy.run` 글자(OCR+dump)를 찾는다(도메인 추정). 다른 링크가 2개 이상이면 멈춘다.
- 링크 탭 후 포커스가 `com.oliveyoung` 이 되길 기다린다. 쓰레드 인앱 브라우저로 열리면 멈춘다.
- 상품 페이지 하단 `구매하기`(y≥1800) → `옵션…선택` 글자가 보이면 멈춤 → `바로구매`(y≥1500) → 주문서(`addrSummaryName`).
- 주문서부터는 3~7번과 같다(`phone_pay` 함수 재사용).
