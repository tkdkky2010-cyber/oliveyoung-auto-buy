# 올리브영 앱 주문서 실측 (2026-11-04, 앱 ver 3.59.0, 1080x2400)

1번 계정, 헤트라스 수선화 ×3 (55,500원)으로 **결제하기 직전까지** 실측. 결제하기(`btnPay`)는 누르지 않았다.
주문서·장바구니는 전부 WebView — dump 의 resource-id = HTML id. 뒤쪽 숨은 WebView 노드도 같이 잡히니 `bounds != [0,0][0,0]` 만 본다.

## 카드 규칙 (사용자 지시 2026-11-04)
- **삼성 쓰지 말 것. 현대·롯데만.** 1번 = 롯데카드(사용자가 직접 선택).

## 1. 장바구니
- 진입: 마이페이지 헤더 `headerBasket` (홈 상단 가방 아이콘도 같은 위치).
- 첫 진입 시 하단 시트 `장바구니가 달라졌어요!` → **확인** (dump 에 없음 → OCR, 실측 (540,2150)).
- 상품 확인(dump 로 정확히 읽힘): CheckBox desc `<상품명> 선택`, 옵션 TextView, 수량 `EditText`(값=수량), `전체 (n/m)`.
- 주문: 버튼 텍스트 `일반배송 구매하기 (N건)` (dump·OCR 둘 다 잡힘).

## 2. 주문서 — 배송지
- `addrSummaryName` = 배송지 이름(예 `1(김건엽)`), `baseDlvpYnFlag` = `기본배송지`, 옆 `변경` 버튼.
- ⚠️ 배송지 변경 목록 화면은 미실측 (1번은 기본배송지가 이미 맞았음).

## 3. CJ ONE 전액사용
- 보유 `point_cjop_label` (예 `2,379P`), 입력 `cjonePntAplyAmt`, 버튼 `cjonePnt_btn`.
- 누르면 네이티브 알림 `CJ ONE 포인트는 10P 단위로 사용하실 수 있어요.` → `button1`(확인).
  알림이 떠 있는 동안 dump 엔 주문서가 안 잡힌다 → 확인 후 다시 읽을 것.
- 적용 검증(실측): `cjonePntAplyAmt`=`2370`, `point_cjop_label`=`9P`, `totPntAplyAmt`=`- 2,370`,
  `totPayAmt_tit_span` 55,500 → `53,130` (= 상품금액 − 차감). **이 셋이 안 맞으면 멈출 것(조용한 SKIP 금지).**

  실측: 2,650P 는 알림 없이 전액 적용, 345P 는 눌러도 반응 없음(최소 사용 기준은 미확인).

### 11-1. 큐레이터 링크 구조 (2026-11-18 PC 웹으로 확인, 폰 미실측)
- 예시 글 `threads.com/@dealzip_/post/DQDkrhNk7XE`: 글 첫 줄 `올리브영 쇼핑 큐레이터 활동의 일환으로…`, 링크는 **본문 텍스트 안**에 `https://oy.run/2WnxCe9`.
  화면엔 **`oy.run/2WnxC…` 로 잘려 보인다** → OCR 로 전체 주소는 못 읽는다. 링크가 1개면 탭 좌표만 쓰면 되니 문제없다.
- `oy.run/<코드>` 는 HTTP 리다이렉트가 아니라 **JS 브릿지 페이지**(200). `window.__SERVER_DATA__.targetUrl` =
  `m.oliveyoung.co.kr/m/goods/getGoodsDetail.do?goodsNo=A000000236450&utm_source=shutter&utm_medium=affiliate&utm_content=OY_<큐레이터 추적값>`.
- 브릿지 JS 가 여는 앱 스킴: **`oliveyoungapp://movePage?deepLinkBridgeUrl=<encodeURIComponent(oy.run 주소)>`** (패키지 `com.oliveyoung`).
  앱이 없으면 플레이스토어 버튼. 큐레이터 추적값은 oy.run 주소를 그대로 넘겨야 유지된다(goodsNo 만으로 열면 빠짐).
- ★**방식 (사용자 지시 2026-11-18): 쓰레드 글 안의 링크를 좌표로 찾아 폰에서 직접 탭한다.** 링크 주소를 알아내서 따로 여는 방식은 쓰지 않는다.
  탭하면 올영 앱으로 넘어간다(사용자 확인). 중간에 뜨는 화면("앱에서 열기" 등)은 폰 실측 때 확인.

## 12. 2026-11-27 실측 — 상품 페이지·옵션·로그인 변경
- 올영 상품 주소(`m.`/`www.oliveyoung.co.kr/.../getGoodsDetail.do?goodsNo=…`)는 `am start VIEW` 하면 올영 앱(MainActivity)이 바로 받는다.
  `adb shell` 은 인자를 폰 셸이 다시 해석하므로 주소는 `shlex.quote` 로 감싼다(`&` 잘림 방지).
- **상품 페이지 하단 버튼 = `장바구니` / `바로구매`** (예전 추정 `구매하기` 는 없음). `wait_landing` 은 OCR `바로구매`(y≥1800) 로 상품 판정.
- `바로구매` → 옵션 목록이 바로 펼쳐짐 + 토스트 `옵션을 선택해 주세요`. dump 에 잡힌다:
